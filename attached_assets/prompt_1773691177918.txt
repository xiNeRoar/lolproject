Build a complete MVP web app called “Vancouver Competitive LoL Project”.

CORE PURPOSE
This is an early-stage Vancouver / Lower Mainland League of Legends competitive community project.
The site should primarily support recruitment and interest collection first, while already having the structure for future small competition events, match results, and a VOD archive.
The long-term direction may evolve into more ongoing local competitive formats, but the first lightweight testing format is 1v1 as a practical starting point before any possible future 5v5 direction.

BRAND / POSITIONING
Working name: Vancouver Competitive LoL Project

Primary hero message:
A place for local players to improve, compete, and be seen.

Tone:
Serious competitive project, but still approachable.

Audience:
Local Vancouver / Lower Mainland LoL players who want a more serious competitive environment, but the site must not feel exclusive, elitist, or intimidating.

IMPORTANT PRODUCT POSITIONING
The site must clearly communicate:
- this is for Vancouver / Lower Mainland players
- this is competitive, but approachable
- this is more than a one-off bracket idea
- this includes replay / VOD archive value
- the first lightweight test may be 1v1, but the project is not permanently limited to 1v1
- this is an earnest grassroots competitive initiative, not a fake large-scale pro league

VISUAL DESIGN DIRECTION
Create a dark, hard-edged, professional competitive website style.
The site should feel closer to a serious tournament / competition hub than a casual gaming website.

Visual rules:
- Mature, restrained, and credible
- Sharp, clean, modern, structured
- Strong hierarchy
- Strong readability
- Clear layout
- Professional desktop-first feel, while still fully mobile responsive
- Background should use dark charcoal / near-black tones
- Use restrained accent colors only
- Accent colors should feel professional and competitive, such as deep blue, steel blue, muted violet, or cool-toned highlights
- Cards and panels should feel slightly sharp / firm rather than soft and playful
- Typography should feel modern, strong, readable, and serious
- Emphasize trust, structure, seriousness, and competitive identity
- The site must not look like a fake Riot clone
- The site must not look like a streamer page
- The site must not look like a gaming gimmick website

Avoid:
- excessive glow
- cyberpunk neon overload
- flashy gradients everywhere
- exaggerated gamer effects
- loud, cheesy esports cliches
- visual clutter
- inconsistent card styles
- random decorative UI patterns
