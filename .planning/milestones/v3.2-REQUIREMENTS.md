**Defined:** 2026-03-27
**Core Value:** Every match submitted via .rofl produces a verified, permanent competitive record that cannot be faked.

## v3.2 Requirements

- [x] **AUTH-06**: GET /auth/me returns `hasPuuid: boolean` field indicating whether player has linked Riot account

- [x] **DOC-03**: PROJECT.md updated — full-stack ownership model, updated constraints, active requirements reflect frontend scope
