**formatters.ts** -- 3 changes to formatMatch:

1. Add `bestOf: m.bestOf ?? null` to the return object (after the `format` field).
   The Drizzle schema has `bestOf: integer("best_of")` and the OpenAPI Match base
   schema declares it at line 2863. Currently missing from formatMatch output.

2. Add `vodCount: 0` as a default field in the return object (after `score`). The
   OpenAPI Match base schema includes `vodCount` (line 2808). Call sites that have
   the actual count (like GET /matches list endpoint at matches.ts line 286) will
   spread their own `vodCount` over this default. Detail and create responses that
   currently lack vodCount will now emit `vodCount: 0` as baseline. This is correct
   because formatMatch cannot know the count without a separate query -- consumers
   override when they have the real value.

3. Remove `eventSlug` from the formatMatch return object AND from the `extra`
   parameter type. The OpenAPI Match base schema does NOT include eventSlug -- it
   is declared only on MatchDetail (line 2894). The list endpoint does not need it
   (MatchListItem extends Match, not MatchDetail). Detail endpoint should add
   eventSlug itself when constructing the MatchDetail response. This keeps
   formatMatch aligned with the Match base contract.
