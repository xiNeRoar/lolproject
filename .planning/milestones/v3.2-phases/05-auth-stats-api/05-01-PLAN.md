**Identity linkage:** `req.session.playerId` is the `players.id` PK (set during Discord OAuth login flow). The DB query uses this to look up the player's `puuid` and `rsoOptIn` fields from `playersTable`.

1. Change `router.get("/me", (req, res) => {` to `router.get("/me", async (req, res) => {`

2. Wrap the body in try/catch (per Pitfall 3 from research -- async handler needs error handling).

3. When authenticated (`req.session.playerId` is truthy):
   - Query: `const [player] = await db.select({ puuid: playersTable.puuid, rsoOptIn: playersTable.rsoOptIn }).from(playersTable).where(eq(playersTable.id, req.session.playerId));`
   - The query selects ONLY puuid and rsoOptIn (minimal data fetch, not full player row).
   - `player` may be undefined if session has stale playerId (player deleted) -- handle with optional chaining.
   - Return JSON with all existing fields PLUS:
     - `hasPuuid: !!player?.puuid` (true when puuid is a non-null, non-empty string)
     - `rsoOptIn: player?.rsoOptIn ?? false` (from playersTable.rsoOptIn, defaults false if player missing)

4. When unauthenticated (per D-06):
   - Return existing fields PLUS `hasPuuid: false, rsoOptIn: false`

5. **Error handling (addresses review concern about catch block masking failures):**
   The catch block MUST log the error via `console.error("[auth]", err)` BEFORE returning the fallback response. This ensures DB/server failures are visible in logs for debugging, while the frontend auth state check still gets a usable response shape (graceful degradation). This is the established pattern in auth.ts -- other handlers (Discord OAuth, RSO callback) also log then return fallback. The catch block returns the unauthenticated shape with `hasPuuid: false, rsoOptIn: false` -- this is safe because a failed DB query means we cannot confirm identity, so defaulting to "not linked" is correct behavior.

Complete replacement code for the handler:

```typescript
// GET /auth/me -- current player session info
router.get("/me", async (req, res) => {
  try {
    if (req.session.playerId) {
      const [player] = await db
        .select({ puuid: playersTable.puuid, rsoOptIn: playersTable.rsoOptIn })
        .from(playersTable)
        .where(eq(playersTable.id, req.session.playerId));

      res.json({
        authenticated: true,
        playerId: req.session.playerId,
        riotId: req.session.playerRiotId ?? null,
        discordUsername: req.session.discordUsername ?? null,
        hasPuuid: !!player?.puuid,
        rsoOptIn: player?.rsoOptIn ?? false,
      });
    } else {
      res.json({
        authenticated: false,
        playerId: null,
        riotId: null,
        discordUsername: null,
        hasPuuid: false,
        rsoOptIn: false,
      });
    }
  } catch (err) {
    console.error("[auth]", err);
    res.json({
      authenticated: false,
      playerId: null,
      riotId: null,
      discordUsername: null,
      hasPuuid: false,
      rsoOptIn: false,
    });
  }
});
```
