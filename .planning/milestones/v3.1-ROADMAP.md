# Milestone v3.1: Launch Preparation

**Status:** SHIPPED 2026-03-27
**Phases:** 1-4
**Total Plans:** 9

## Overview

VCLoL's backend was functional but had security gaps, missing schema columns, and incomplete privacy enforcement that blocked launch. This milestone fixed the foundation (schema sync + auth hardening), implemented the 3-layer privacy model required by Riot policy, aligned the API contract and performance, and cleaned up spec drift.

## Milestone Summary

**Key Decisions:**
- visibleAfter = null means PRIVATE permanently (D-11), not 7-day default
- Participant check uses match_players table, not team_members (D-03)
- Redacted response uses isRedacted flag, not _private (D-02)
- RSO tokens: keep schema columns, don't populate (trigger: Tournament API milestone)
- CORS allowlist uses PLATFORM_URL env var with localhost fallbacks in dev only
- Session secret validation exits process with code 1 in production (fail-fast)
- Players pagination is admin-only
- Matches GET / filters moved from JS to SQL WHERE with conditions builder pattern

**Issues Resolved:**
- GitHub #217: GET /players N+1 query (closed by Phase 03-02)
- GitHub #221: match_type column missing (closed by Phase 01-01)
- VOD 7-day auto-public bug (closed by Phase 02-02)
- Inline visibility logic divergence (consolidated in privacyGate.ts by Phase 02)

**Issues Deferred:**

- Codegen regeneration (node/pnpm not available in dev shell during Phase 4)
- Per-team W/L + KDA stats for player profile (FEND-03, next milestone)
- /auth/me missing hasPuuid field (needed for frontend login flow)
