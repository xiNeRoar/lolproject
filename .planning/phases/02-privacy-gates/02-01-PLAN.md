1. **`async function checkMatchParticipant(matchId: number, playerId: number): Promise<boolean>`** (per D-03)
   - Query `match_players` WHERE `matchId = matchId AND playerId = playerId`, LIMIT 1
   - Return `!!row` -- true if this playerId is one of the 10 actual match participants
   - MUST use `matchPlayersTable` (NOT `teamMembersTable` -- D-03 explicitly says participant = 10 players in match_players)
   - Import from `@workspace/db`: `db`, `matchPlayersTable`, `matchesTable`, `playersTable`
   - Import from `drizzle-orm`: `eq`, `and`, `inArray`

2. **`async function isMatchVisibleTo(match: Match, viewerId: number | null, isAdmin: boolean): Promise<{ canSeeStats: boolean; isParticipant: boolean }>`** (per D-01, D-02, D-05)
   - If `isAdmin` => `{ canSeeStats: true, isParticipant: false }`
   - Read `matchType` from `match.matchType` (column exists, text, default "scrim")
   - If `matchType === "ranked_tournament" || matchType === "event"`:
     - If `match.visibleAfter` exists AND `match.visibleAfter.getFullYear() >= 9000` (captain set private):
       - Check participant via `checkMatchParticipant` if viewerId exists
       - Return `{ canSeeStats: isParticipant, isParticipant }`
     - Otherwise return `{ canSeeStats: true, isParticipant: false }` (tournament/event always public per D-05)
   - For scrims (everything else):
     - If viewerId exists, check participant via `checkMatchParticipant`. If participant => `{ canSeeStats: true, isParticipant: true }`
     - If `match.visibleAfter` is NOT null AND `Date.now() >= match.visibleAfter.getTime()` => `{ canSeeStats: true, isParticipant: false }` (captain set public)
     - Otherwise => `{ canSeeStats: false, isParticipant: false }` (null visibleAfter = private per D-11)
   - Use type `Match` from `@workspace/db` (or `typeof matchesTable.$inferSelect`)

3. **`function redactMatchForNonParticipant(formattedMatch: Record<string, any>): Record<string, any>`** (per D-01, D-02)
   - Return an object with ONLY these fields from the input:
     - `id`, `teamAId`, `teamBId`, `teamAName`, `teamBName`, `teamATag`, `teamBTag`, `sideAName`, `sideBName`, `matchTitle`, `winnerName`, `score`, `gameDuration`, `createdAt`, `updatedAt`, `matchType`
   - Add `matchPlayers: []`, `vods: []`, `isRedacted: true`
   - Do NOT include: `roflFilePath`, `visibleAfter`, ELO fields, `gameId`, `gameVersion`, or any per-player data
   - NOTE: D-01 says game duration IS included in redacted view

4. **`async function filterMatchPlayersByOptIn(matchPlayers: Array<Record<string, any>>, viewerIsParticipant: boolean): Promise<Array<Record<string, any>>>`** (per D-04)
   - If `viewerIsParticipant` return matchPlayers unchanged (participants always see all)
   - Collect all non-null `playerId` values from matchPlayers
   - Batch query `playersTable` WHERE `id IN (playerIds)` to get `rsoOptIn` status for each
   - Build a `Map<number, boolean>` of `playerId => rsoOptIn`
   - Map over matchPlayers: if player's `rsoOptIn` is true (or playerId is null), return as-is. Otherwise return a masked version:
     ```
     { ...mp, playerRiotId: null, champion: null, kills: null, deaths: null, assists: null, cs: null, gold: null, damageToChampions: null, visionScore: null, item0: null, item1: null, item2: null, item3: null, item4: null, item5: null, item6: null, _masked: true }
     ```

5. **`async function isPlayerProfileVisibleTo(player: Player, viewerId: number | null, isAdmin: boolean): Promise<{ canSeeProfile: boolean; isOwner: boolean }>`** (per D-07, D-08, D-09)
   - If `isAdmin` => `{ canSeeProfile: true, isOwner: false }`
   - If `viewerId === player.id` => `{ canSeeProfile: true, isOwner: true }`
   - Read `player.profileVisibility` (default "private")
   - If `"public"` => `{ canSeeProfile: true, isOwner: false }`
   - If `"participants-only"` and viewerId exists => call `checkCoParticipant(player.id, viewerId)`. If co-participant => `{ canSeeProfile: true, isOwner: false }`
   - Otherwise => `{ canSeeProfile: false, isOwner: false }`

6. **`async function checkCoParticipant(targetPlayerId: number, viewerPlayerId: number): Promise<boolean>`** (per D-09)
   - Query: find any match where both `targetPlayerId` AND `viewerPlayerId` appear in match_players
   - Use a subquery or join: `SELECT 1 FROM match_players mp1 INNER JOIN match_players mp2 ON mp1.matchId = mp2.matchId WHERE mp1.playerId = targetPlayerId AND mp2.playerId = viewerPlayerId LIMIT 1`
   - With Drizzle, use `db.select({ id: matchPlayersTable.id }).from(matchPlayersTable).where(eq(matchPlayersTable.playerId, targetPlayerId)).innerJoin(sql..., sql...)` pattern from existing code in players.ts line 399-407
   - Return `!!row`
