**File 2: artifacts/api-server/src/routes/auth.ts**

Add import at the top of the file (if not already present):
```typescript
import crypto from "node:crypto";
```

Then modify all 3 OAuth flows:

**Flow 1 — Discord OAuth initiation (GET /discord, ~line 20-28):**
Add state generation before the redirect:
```typescript
const state = crypto.randomBytes(32).toString("hex");
req.session.oauthState = state;
```
Add `state` to the URLSearchParams object.

**Flow 2 — Discord callback (GET /discord/callback, ~line 31):**
Add state validation at the start of the handler, before the code exchange:
```typescript
const state = req.query.state as string;
if (!state || state !== req.session.oauthState) {
  res.status(403).json({ error: "Invalid OAuth state" });
  return;
}
delete req.session.oauthState;
```

**Flow 3 — RSO OAuth initiation (GET /rso, ~line 94):**
Same pattern — generate state, store in session, add to URL params:
```typescript
const state = crypto.randomBytes(32).toString("hex");
req.session.oauthState = state;
```
Add `state` to the RSO authorization URL params.

**Flow 4 — RSO callback (GET /rso/callback, ~line 130):**
Same validation pattern:
```typescript
const state = req.query.state as string;
if (!state || state !== req.session.oauthState) {
  res.status(403).json({ error: "Invalid OAuth state" });
  return;
}
delete req.session.oauthState;
```

**Flow 5 — /connect/:token RSO initiation (~line 200):**
Same pattern — generate state, store in session, add to URL params.

**Flow 6 — /connect/callback (~line 230):**
Same validation pattern. Note: this flow also has connectToken and connectDiscordId in session — do NOT remove those. Only add and validate oauthState.

IMPORTANT: Use a single `oauthState` key for all flows (not separate keys per provider). Only one OAuth flow can be in progress per session at a time, so a single key is sufficient and avoids complexity.
