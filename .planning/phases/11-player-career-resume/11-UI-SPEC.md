## Component Inventory

### New Component: Career Card Section

**Location:** Inline within `PlayerProfile.tsx` (no separate component file needed -- follows existing pattern where Badges, Champion Pool, Events are all inline)

**Placement:** Between the Badges section and the ELO Trajectory section. Insertion point is after line 321 (`)}`) closing the badges block and before line 323 (`{allTeams.length > 0 && <EloTrajectory ...`).

**Data source:** `useGetPlayerTeamStats(player.id)` -- new hook import from `@workspace/api-client-react`

**Deduplication logic:** If API returns multiple entries with the same `teamId`, merge into one card: sum `wins`, `losses`, `gamesPlayed`; weighted-average `avgKills`, `avgDeaths`, `avgAssists` by `gamesPlayed`; use latest `joinedAt`; use latest `status` and `role`.

## Layout Specification

### Career History Section Structure

```
Card (bg-card/40 border-border/40 mb-6)
  CardHeader (pb-3)
    CardTitle (text-base font-display flex items-center gap-2)
      Users icon (w-4 h-4 text-primary)
      "Career History"
  CardContent (p-0)
    divide-y divide-border/30
      [For each team card]:
        div (px-6 py-3 flex items-center gap-4)
          LEFT BLOCK (flex-1 min-w-0):
            Row 1: Team name (Link, text-sm font-medium hover:text-primary) + [TeamTag] (text-muted-foreground)
            Row 2: Role Badge (variant="outline", text-xs) + Status indicator + Joined date
          RIGHT BLOCK (text-right shrink-0):
            Row 1: Win/Loss (text-sm font-medium) -- "5W / 3L" with green-400/red-400
            Row 2: KDA average (text-xs text-muted-foreground) -- "4.2 / 2.1 / 8.3"
            Row 3: Win rate % + Games played (text-xs text-muted-foreground)
```

### Per-Card Row Layout Detail

Left side:
- Team name as Link: `text-sm font-medium hover:text-primary transition-colors truncate block`
- Team tag inline: ` [TAG]` in `text-muted-foreground`
- Role badge: Badge variant="outline" with `text-xs`. Only render if `role` is not null.
- Status: For inactive teams, render `text-xs text-muted-foreground` text "Inactive". For active, no label needed.
- Joined date: `text-xs text-muted-foreground` formatted as "Joined Mon YYYY" using `date-fns` or `toLocaleDateString("en-CA", { year: "numeric", month: "short" })`

Right side:
- W/L record: `<span class="text-green-400">{wins}W</span> / <span class="text-red-400">{losses}L</span>` at `text-sm font-medium`
- KDA: `{avgKills.toFixed(1)} / {avgDeaths.toFixed(1)} / {avgAssists.toFixed(1)}` at `text-xs text-muted-foreground`
- Win rate and games: `{winRate}% WR` (color-coded per threshold table above) + ` -- {gamesPlayed} games` at `text-xs text-muted-foreground`

### Ordering

Career cards sorted by: active teams first, then by `gamesPlayed` descending. Inactive teams appear after all active teams, also sorted by `gamesPlayed` descending.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Section heading | "Career History" |
| Empty state (no teams) | Section not rendered. No career cards = no section visible. (Matches pattern: Badges section hides when badges.length === 0, Champion Pool hides when championStats.length === 0) |
| Empty state (teams but zero games) | Card renders with "0W / 0L" and "0.0 / 0.0 / 0.0" KDA and "0 games" -- no special empty message needed |
| Error state (hook failure) | Section not rendered. useGetPlayerTeamStats failure silently hides section. (Matches existing pattern: badges/championStats/events all hide on undefined data) |
| Role badge null | No badge rendered. Gap collapses naturally. |
| Joined date label | "Joined {Mon YYYY}" -- e.g. "Joined Mar 2026" |
| Inactive status label | "Inactive" in `text-muted-foreground text-xs` |
| Win rate suffix | "{N}% WR" |
| Games played suffix | "{N} games" (or "{N} game" if exactly 1) |

No destructive actions in this phase. No confirmation dialogs needed.

## Interaction States

| State | Behavior |
|-------|----------|
| Loading | Section not rendered until data arrives. No dedicated skeleton for this section -- page-level skeleton (lines 139-147) already covers initial load. Hook is enabled only when `player?.id` is truthy. |
| Hover on team name | `text-primary` color transition via `hover:text-primary transition-colors` |
| Click on team name | Navigate to `/teams/:teamId` via wouter Link |
| Inactive card | Entire card row gets `opacity-60` class |
| Zero games team | Renders normally with zeroed stats -- no special visual treatment |
| Deduplication merge | Transparent to user -- they see one card per team regardless of leave/rejoin |

## Animation

Follow existing page pattern: No Framer Motion on individual career cards. The career section appears as part of the natural page flow. Page-level `motion.div` entrance animation (if present on parent) covers it.

## Responsive Behavior

Career cards use the same responsive pattern as Events section (which is structurally identical -- `divide-y` rows with left/right layout):
- Desktop: Horizontal row with left info + right stats
- Mobile: Same layout compresses naturally. `truncate` on team name prevents overflow. `shrink-0` on right block keeps stats visible.
- No breakpoint-specific overrides needed. `flex items-center gap-4` with `flex-1 min-w-0` handles all widths.
